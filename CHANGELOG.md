# Changelog

All notable changes to OpenBlock are listed here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [0.2.0] - 2026-10-27

### Added
- **Menu bar app**: status, *Update Filters Now*, *Pause Blocking* and *Launch at Login*. The Dock icon only shows while the window is open; Settings has "Keep OpenBlock in the menu bar only".
- More rules recovered from the AdGuard lists for the Advanced extension (wildcard-TLD domains, extended CSS).
- DMG packaging script (`scripts/make-dmg.sh`), CI, and contributor documentation.

### Fixed
- Blockers now reload as soon as you return to the app.

## [0.1.0] - 2026-10-27

First release: four Safari content blockers, the converter, the OpenBlock Advanced web extension, user rules, allowlist and auto-update.
